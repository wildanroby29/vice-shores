# Vice Shores — 3D open-world crime

[![make.fun](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01)
[![rank](https://make.fun/badge/gta6-01/wildanroby29/vice-shores/rank.svg)](https://make.fun/bounty/gta6-01)
[![reward](https://make.fun/badge/gta6-01/wildanroby29/vice-shores/reward.svg)](https://make.fun/bounty/gta6-01)

An original 3D open-world crime game for the make.fun "Make GTA 6" bounty
(gta6-01): a sun-soaked coastal city you explore on foot and by car, with
traffic and pedestrians, cars to steal, a 0–5 star wanted system with police
pursuit, roadblocks and a helicopter, 8 numbered story missions for the fixer
Marla, combat, a dense HUD with a minimap, a start screen with 3 save slots,
and a garage/airbrush workshop. Everything — the city, characters, vehicles,
names, story, art and sound — is original; nothing comes from Rockstar Games.

Play it: serve `game/` with any static server (`node serve.ts`, then
http://localhost:8080) and open `game/index.html` in desktop Chrome.
WASD drive/walk, E enter & steal cars, Space shoot, Shift sprint, 1–4
weapons, R reload, Q/C/V crew abilities, G garage, P pause, M radio.
