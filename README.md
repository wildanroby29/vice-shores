[![rank badge](https://make.fun/badge/gta6-01/wildanroby29/vice-shores/rank.svg)](https://make.fun/bounty/gta6-01)
[![reward badge](https://make.fun/badge/gta6-01/wildanroby29/vice-shores/reward.svg)](https://make.fun/bounty/gta6-01)

An original 3D open-world crime game set in Vice Shores, a sun-soaked coastal
city: drive the boulevard, steal cars, outrun the police (5-star wanted
system, helicopter and roadblocks), run 8 story jobs for fixer Marla, upgrade
your ride at Vice Customs, and climb the respect ladder from NOBODY to
TIDE BOSS.

- Third-person driving and on-foot play, traffic, pedestrians, carjacking,
  weapons, health and armour, crew abilities, radio, minimap and a
  full-screen city map, dialogue, save slots, garage upgrades.
- Built with three.js (vendored), plain static files — open `game/index.html`
  in a desktop browser, or serve with `node serve.ts` on port 8080.
- Controls: WASD drive/walk, E enter/steal car, Space shoot, Shift sprint /
  nitro, C camera, M map, G customs, R radio, Q weapon, P pause.
